# uts-graf-sains-data
Analisis graf dan rekomendasi item menggunakan dataset RetailRocket

## Metode
- Representasi interaksi pengguna dan item.
- Analisis graf dan proyeksi graf.
- Rekomendasi item menggunakan K-Nearest Neighbors (KNN).
- Evaluasi rekomendasi menggunakan Hit@5 dan NDCG@5.

## Dataset
Dataset yang digunakan adalah RetailRocket. Dataset dapat diperoleh dari sumber aslinya:
https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset
